How the trick works

01

Text → bits

Message becomes bytes via TextEncoder, then 1s and 0s. "A" is byte 65 = 01000001.

02

Bits → pixels

Each bit replaces the last bit of a pixel channel. Below, highlighted bits spell 01001000 = "H".

C8 C9 CA CB CC CD CE CF 11001000 11001001 11001010 11001010 11001101 11001100 11001110 11001110
03

The header

9 bytes first: magic STEG, encryption flag, message length. Decode reads it to know a message exists and where it ends.
